# Casos de teste - Etapa 2 (Par de Pontos Mais Proximos)
#
# Formato de cada caso:
#   === <nome> | <justificativa>
#   <entrada: n seguido de n linhas "x y">
#   --- esperado
#   <distancia>                    (6 casas decimais)
#
# So a distancia e comparada (tolerancia 1e-6), porque pode haver varios pares empatados.
# O executor tambem confere se o par devolvido realmente tem a distancia informada.
# Cada caso e executado com forca bruta e com divisao e conquista em varios limiares
# (3, 4, 8 e o padrao 32), para que os casos pequenos exercitem a recursao e a faixa.
